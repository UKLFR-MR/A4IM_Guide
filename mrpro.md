# MRpro

## Project Overview
MRpro is a robust software framework dedicated to the handling of raw MRI data, advanced image reconstruction, and cloud-based database connectivity. It acts as a bridge between raw signal acquisition and the final interpretable medical images.

## Documentation and Resources
The MRpro documentation is designed to support both casual users aiming to reconstruct standard datasets and advanced developers building custom reconstruction pipelines.

### 1. User Guides and Technical Manuals
* **Official Documentation Hub:** The central archive for MRpro manuals is located at [docs.mrpro.rocks](https://docs.mrpro.rocks/data.html). While the [repository](https://github.com/PTB-MR/mrpro) is available on GitHub.
The documentation hub provides information on installation, usage, data structures and many examples.
* **Data Handling:** Detailed explanations on how MRpro ingests raw data formats exported from platforms like Scanhub or MaRGE, and how it prepares this data for reconstruction.

### 2. Hands-On Tutorials and Workshops
To facilitate learning, the project provides practical, step-by-step tutorials:
* **Low Field Reconstruction Lab:** A comprehensive set of Jupyter Notebooks and tutorials created for the A4IM Turin 2026 workshop. This lab provides interactive examples of loading data, applying filters, and executing reconstruction algorithms. [Access the Tutorial Repository](https://github.com/ckolbPTB/LowFieldReconstructionLab/tree/a4im_turin_2026).

### 3. Database Integration
* **XNAT Connectivity:** There is also a [repository](https://github.com/PTB-MR/mrpro_xnat/blob/main/walkthrough.ipynb) available which allows to connect MRpro with XNAT. Additionally a Juniper Notebook provides a [walktrough](https://github.com/PTB-MR/mrpro_xnat/blob/main/walkthrough.ipynb) on how to run MRpro inside XNAT.
