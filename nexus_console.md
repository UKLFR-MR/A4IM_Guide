# NEXUS Console

## Project Overview
The NEXUS Console is an open-source Python software framework that drives the Spectrum-Instrumentation measurement cards. The powerfull computing hardware in combination with the software are acting as both an acquisition system and a powerful edge-computing reconstruction unit.

## Documentation and Resources
A summery of the NEXUS Console is hosted at [opensourceimaging.org](https://www.opensourceimaging.org/project/nexus-console/) and the [official documentation](https://schote.github.io/nexus-console/) is available via GitHub.
An open access [publication](https://onlinelibrary.wiley.com/doi/full/10.1002/mrm.30406) is also available.

* **Quick-Start Guide:** A streamlined guide designed to get your hardware and software environment configured rapidly. It details the necessary prerequisites and walks through the initial installation process. [View the Quick-Start Guide](https://schote.github.io/nexus-console/quick_start.html).
* **GitHub Repository:** The core source code and issue tracker can be found on [GitHub](https://github.com/schote/spectrum-console).

### 2. User Manuals and Core Concepts
* **User Guide:** The primary manual detailing the key concepts of the package. ### 3. Practical Usage and How-Tos
* **Example Experiments:** For hands-on learning, the documentation includes a collection of example programs. ### 4. API Reference for Developers

This section breaks down the Spectrum-Console API, describing the inner workings of methods, available parameters, and return types.
