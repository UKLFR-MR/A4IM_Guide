# Scanhub

## Project Overview
Scanhub is the overarching open-source platform that unifies the diverse software and hardware modules of this project. Designed primarily around the Nexus hardware architecture, it provides a cohesive interface for patient management, scanner control, and automated data workflows, acting as the bridge to cloud-based databases.
